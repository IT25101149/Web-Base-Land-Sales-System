# Web-Based Land Sales System - Spring Boot Starter Structure

Based on the project proposal:
1. Property Management
2. Land Survey & Valuation Management
3. Customer Relationship Management
4. Sales, Payment & Reservation Management
5. Document & Legal Issue Management
6. Administration & System Management

Stack: Java, Spring Boot, JSP, MySQL, Spring Data JPA, Spring Security, Maven.
This is a project structure/starter skeleton, not a completed implementation.
